## Abrir e hospedar

1. Baixe o ZIP do repositório e extraia a pasta site-servicos.
2. Abra index.html no navegador para conferir o conteúdo e as imagens.
3. Hospede index.html, styles.css e a pasta assets juntos em um serviço compatível com HTML estático. README.md não precisa ser publicado.
4. Na Hostinger com hospedagem de arquivos, use a pasta public_html de um site/subdomínio escolhido. Não sobrescreva um site existente.
5. Se o site foi criado no Hostinger Website Builder, o fluxo de upload de arquivos não é equivalente; confirmar o produto disponível antes de publicar.
6. Configure o domínio e HTTPS pelo provedor. Nenhum domínio foi comprado ou assumido disponível.
7. Após publicar, teste navegação, imagens, celular, zoom de 200% e envio pelo seu aplicativo de e-mail.

O GitHub está sendo utilizado para guardar o código, não como hospedagem comercial desta página. Não foi habilitado GitHub Pages.

Referência Hostinger: https://www.hostinger.com/support/4548688-basic-actions-in-the-file-manager-in-hostinger/

## Como usar para captar clientes

O site apresenta a oferta e permite contato; não traz visitantes automaticamente.

- Contatos profissionais e indicações: compartilhar a página com uma mensagem específica sobre o problema atendido.
- Parcerias com contadores, consultores e pequenas agências: conversar sobre demandas de relatórios dos clientes.
- Grupos de empreendedores: publicar uma demonstração útil quando as regras do grupo permitirem.
- 99Freelas e Workana: usar os recursos de proposta e portfólio da plataforma e seguir suas regras de contato e pagamento, sem direcionar clientes para contratação por fora.

Começar com poucos canais e registrar origem, necessidade, prazo, orçamento e status de cada oportunidade. Não foram enviados contatos ou criadas campanhas.
